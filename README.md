# Slabline landing pages

Static site served by GitHub Pages at https://slabline.glintvex.com

- `index.html`: main landing page
- `scorecard.html`: Wasted-Drive Scorecard (lead magnet)
- `concrete-cost-calculator.html`: concrete driveway/patio cost calculator (lead magnet, SEO)
- `thanks.html`: post-booking page
- `config.js`: settings (lead inbox, Calendly link, Instagram). Change values here, not in the pages.
- `lead.js`: form sending via FormSubmit
